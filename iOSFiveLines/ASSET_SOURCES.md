# 彩蛋资源来源

- `lbxx.mid`、`twzd.mp3` 由用户提供。iOS 播放的 `lbxx.mp3` 从原始 MIDI 使用 FluidSynth 2.6.0 和 GeneralUser GS 2.0.3 渲染；原始 MIDI 同时保留在项目中。GeneralUser GS 音色库没有打包进应用。
- 宝马、奥迪、法拉利、兰博基尼、保时捷、凯迪拉克、尼桑的车标轮廓取自 [Simple Icons 16.31.0](https://github.com/simple-icons/simple-icons)，按 CC0-1.0 发布。奔驰三叉星和道奇双斜杠为本项目绘制。Android 与 iOS 使用同一组透明棋子图形。
