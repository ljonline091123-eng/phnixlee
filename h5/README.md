# 五彩连线 H5 版

这是一个无需编译的静态 H5/PWA 版本，入口文件是 `index.html`。

当前版本使用轻松的五声音阶背景旋律，并为炸药加入了独立的引线、低频爆炸和碎裂尾音效果；音乐和音效均可在“设置”中分别开关和调节音量。

## 电脑打开

直接双击 `index.html` 即可开始游戏。棋盘、动画、设置和高分榜都在浏览器本地保存。

## 手机打开

把 `h5` 文件夹放到任意静态网页托管服务，使用手机浏览器打开网址；在 Safari 或 Chrome 菜单中选择“添加到主屏幕”，即可像 App 一样启动。

## 本地局域网测试

如果电脑安装了 Python，可以在 `h5` 目录执行：

```text
python -m http.server 8080
```

然后在电脑打开 `http://localhost:8080`。手机和电脑连接同一 Wi-Fi 时，可用电脑局域网 IP 打开同一地址。

直接双击页面时，游戏本体可运行；Service Worker 离线缓存需要通过 `http://` 或 `https://` 地址打开。
