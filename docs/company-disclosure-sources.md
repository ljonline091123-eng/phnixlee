# 供应链、经营往来与司法披露接入

本轮在既有公司关系模块中增量接入三类公开披露。入口为“公司关系 → 来源与治理任务”，勾选股票及对应采集选项。股票和公司入口共享同一公司证据，原有身份映射、股权事实、行业和标签不重建。

## 数据来源和实际边界

| 类别 | 已接入的公开来源 | 当前保存的内容 |
| --- | --- | --- |
| 供应链 | [巨潮资讯](https://www.cninfo.com.cn/)完整年度报告、供应商/客户、采购、销售、日常关联交易披露 | 公告标题、PDF 链接、提取正文、页码、原文片段、内容摘要值、筛选依据；匿名客户不解析成公司 |
| 经营往来 | 巨潮合同、中标、采购、担保、关联交易公告 | 原文与待核实片段；签约、中标、履约、收入需分别治理 |
| 司法事项 | 巨潮诉讼、仲裁公告 | 原文、案号提及、页码；不把披露主体或母公司直接认定为案件当事人 |

三类来源代码为 `CNINFO_SUPPLY_CHAIN_DISCLOSURES`、`CNINFO_BUSINESS_DISCLOSURES`、`CNINFO_LEGAL_DISCLOSURES`，共用公司披露适配器，已注册为数据源及接口并关联现有治理智能体。旧来源、接口、智能体、Skill 的用户配置不会被覆盖。

上述是上市公司披露渠道，覆盖中国 A 股；港股独立采集当前返回“暂不支持”。A/H 同发行人的港股入口可查看通过其 A 股归档的公司披露，不代表已接入港交所。

配置法院 API URL/token 只显示“已配置，尚未验证”，不会自动显示“已连接”。公开网页入口不等于可免费批量查询的 API。

## 原文与关系的区分

采集输出保存为 `FoundationEvidence`。供应链新增 `SUPPLY_CHAIN_DISCLOSURE`，与经营、司法文档分类并存；同一公司同一公告同一文本重复导入不增加正文版本。一份公告可以具备多类用途，新增分类保留记录时间。

关键词片段和案号只标注“待核实”，不自动写入已接受的 `SUPPLIES_TO`、`CONTRACT` 或 `LEGAL_CASE`。建立关系还需要核对具体主体、对手方、方向、业务期间、金额口径及当事人角色。没有找到披露不代表没有交易或诉讼。

覆盖矩阵分别展示“已接受事实、待审事实、事实证据、披露份数”。仅有文档时页面显示“仅有披露线索”，后台 `missing` 仍保留关系事实缺口，不冒充治理完成。

## 采集范围

- 每次最多 30 只股票，每类默认最多 2 份 PDF；标题关键词每词只查询首 30 条，不是全历史检索。
- 供应链、经营默认从 2025-01-01 开始，司法从 2024-01-01 开始；结束日期为采集当天。
- 供应链优先选择最新完整年报正文和直接供销经营公告，排除摘要、英文版、半年报、说明会及股权/资产交易等干扰结果。
- PDF 最大 20 MB、提取前 100 页且最多 200 万字符。达到截断条件返回“部分获取”；后续章节可能缺失，可打开原始 PDF 核对。
- PDF 下载失败保存标题和链接并标记“仅有公告信息”；扫描件标记“需文字识别”。每份文档最多 20 个关键词片段，每段最多 500 字，均来自实际提取页。

## 验证入口

在公司关系工作台选择美的集团（000333）、中国中车（601766）或海航控股（600221），分别打开“供应链”“经营往来”“司法事项”。点击公告标题查看片段、正文状态及页码，再打开官方 PDF 交叉核对。司法仅在实际存在披露的公司显示记录。

已有公司映射可以单独导入缓存披露，避免重做主数据：

```powershell
cd backend
python scripts/collect_company_sources.py --cache-dir tmp_company_sources --section supply_chain --symbols '000333,600221,601766' --max-documents 2
python scripts/import_company_disclosures.py --database-url sqlite:///quant.db --cache-dir tmp_company_sources --symbols '000333,600221,601766' --report validation/disclosure-import.json
```

正式运行前备份 SQLite；导入脚本只增加来源注册、公告证据/提取注释和运行记录，不修改股权及其他已接受事实。前端治理任务则走既有队列，新增请求字段 `include_supply_chain`；旧 API 请求省略该字段时仍不采集供应链。

## 2026-09-21 实际验证

- 20 只 A 股已尝试供应链采集；当前公司证据中包含供应链候选披露 38 份、经营披露 16 份、司法披露 3 份。数量不代表关系条数，也不代表所有公司均有司法事项。
- 多数年报达到 100 页提取上限，状态为部分获取；紫金矿业的一份年报只归档了标题及链接，未取得可用正文。
- 25 只证券与 20 家公司的双对象映射验收通过；112 项相关后端测试、前端构建、真实浏览器页面验证通过；中国中车单股供应链任务通过正式 API 入队并完成。
- 原有股票、公司、股权、分类、模型、智能体和 Skill 记录保留。旧公告正文、哈希及版本保留，部分证据新增文档分类或提取注释。
- 本地数据库快照：`backend/backups/pre-disclosure-sources-20260921-2230.db`。采集报告、验收报告及截图在 `backend/validation/disclosure-*`。
