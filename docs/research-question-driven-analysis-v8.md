# V8 研究问题驱动分析

V8 不替换现有湖仓、知识库、知识图谱、GraphRAG 或八维评分。八维评分继续作为结果展示和质量校验层，研究过程先围绕四个问题组织证据，再形成整体结论：

1. **公司赚钱逻辑（BUSINESS_MODEL）**：主营产品、收入结构、利润质量、现金流和持续性。
2. **重大管理层变化（MANAGEMENT_CHANGE）**：职务变化、生效日期、官方原因、职责交接、经营连续性和竞争性解释。
3. **并购与第二曲线（ACQUISITION_SECOND_CURVE）**：标的、对价、交割、并表、协同、整合风险和收入利润兑现。
4. **资本行为动因（CAPITAL_ACTION_INTENT）**：回购、注销、增减持、解禁和锁定安排的多种可能动因及后续验证。

每个问题都必须区分事实、推断、假设和未知，保存支持证据、反证、缺口、补证计划和跟踪指标。重大事件适用时至少提出两条竞争性假设；没有事件时使用 `NOT_APPLICABLE`，不得为了填满字段虚构事件。

外部互联网信息不能直接进入结论。系统先给出优先官方来源、检索词和缺口影响，补证资料入湖仓并生成可追溯文档后，才允许重新分析。`RESEARCH_QUESTION_PLANNER`、`EVIDENCE_GAP_DETECTOR`、`MANAGEMENT_CHANGE_DEEP_DIVE`、`ACQUISITION_IMPACT_ANALYST`、`CAPITAL_ACTION_INTENT_ANALYST`、`PEER_BENCHMARK_ANALYST`、`COUNTER_EVIDENCE_REVIEWER` 和 `CONCLUSION_QUALITY_GATE` 均为只读 Skill，不执行任意 SQL 或数据库写入。

历史 V7 结果保持只读兼容，新建分析和失败重试使用 `FUNDAMENTAL_RESEARCH_V8`。研究未完成时不再简单停留在“待补证”，而是由 `HYPOTHESIS_RESEARCH_ORCHESTRATOR` 进入以下受控闭环：

```text
重大事件 → 竞争性假设 → 证据需求 → 已接数据源补数 → 知识投影 → 单股重验
       ↑                                                        ↓
       └──────────── 证据增量与置信度更新 ←──────────────────────┘
```

- 只调用系统已经登记的数据源、采集服务、知识投影和单股重验，不执行任意 SQL，也不由 LLM 直接写业务表。
- 每轮冻结研究问题、假设、补数范围、来源、补数前后证据指纹、新增文档/事实/关系、模型结果与置信度变化。
- 默认最多三轮。发现新增证据后重新验证；没有新增证据时置信度乘以 0.65；连续两轮没有新增证据时，次级假设置信度上限降至 0.20 并关闭该方向。
- 支持证据、弱支持、明确反证分别由模型按证据契约判断，程序只执行确定性置信度更新。模型不能自由修改更新规则。
- 主营赚钱逻辑属于发布硬门槛；管理层动机、资本行为动机等次级推理在有界研究结束、置信度已降至低位后，不再永久阻塞整只股票的其他结论。
- `RESEARCH_RUNNING` 表示自动补数研究正在执行；`RESEARCH_INCOMPLETE` 表示主营硬缺口或仍有高置信开放假设；`READY_REVIEW_WITH_UNCERTAINTY` 表示核心证据成立、未获支持的次级方向已低置信关闭，可带保留项进入人工复核。

前端“事件驱动研究闭环”展示每轮调用板块、证据增量和终止原因。八维评分只在研究结论形成后作为结果表达与跨股票比较，不再作为研究起点。

补数和验证状态严格区分：已接来源调用超时、接口异常或模型重验失败分别记录为 `SOURCE_FAILED`、`MODEL_FAILED`，保留上一轮假设、结论和已采集证据，并允许幂等重试；这些失败轮次不得作为“查无证据”，也不得触发置信度衰减。只有来源成功查询且没有形成新增文档、事实、关系或结构化观测时，才计入 `NO_NEW_EVIDENCE`；连续两轮无增量后，未获支持的次级假设降为低置信关闭。每轮模型重验必须继承上一轮竞争性假设、支持/反证、当前置信度、失效条件和研究回执，只能根据新增证据更新同一问题，不得重新发明一组无关假设。
