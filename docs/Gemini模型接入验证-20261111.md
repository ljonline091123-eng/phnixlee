## 使用入口

- 模型管理：查看 Gemini 型号、调用状态与错误详情；配额恢复后可重新测试。
- AI证券分析师 → 分析模型：刷新页面后可选择新增型号。
- 本轮保留现有任务路由，未擅自将全部任务切换至新型号。

Gemini 网页 Pro 订阅与 Google API 项目的计费、配额独立。官方目录可见、网页可以对话，均不代表当前 API Key 可以成功生成。

## 代码及配置变更

- `backend/app/services/model_hub.py`：增量同步 Gemini 目录，新增三个已验证的文本型号；纠正原 Flash-Lite、Pro、Carbon 实际调用编码；保留原实例 ID、自定义设置、删除标记及路由。为 3/4 代模型保存原生 thinkingLevel 参数。
- `backend/app/connectors/model_adapters.py`：3/4 代使用 thinkingLevel，2.5 代保留 thinkingBudget；连通性检查为可见输出预留预算；过滤思考片段；空正文和截断的连通性响应不得报成功。
- `backend/app/api/model_hub.py`：状态与信号统计同时匹配实例编码和当前调用型号，避免旧型号成功记录误判新型号可用；Gemini 配额失败显示“API额度不足”。
- `backend/app/services/model_errors.py`：Google 免费层配额错误采用中文说明，区分 API 配额与网页订阅。
- `backend/scripts/register_gemini_tiers.py`：将原删除重建脚本改为增量登记，要求提供独立数据库备份，保留 ID、密钥、路由及调用历史。
- `backend/tests/test_gemini_catalog.py`：覆盖增量目录、删除保护、幂等、健康状态、思考参数、原生 JSON、空响应与配额错误。
- 调整 `test_core_model_refactor.py`、`test_model_hub.py` 的路由测试，使其与本轮修改前已有路由一致，使用显式路由验证故障转移。

本轮无数据库表结构迁移；原 14 个模型实例保留，新增 3 个 Gemini 实例，共 17 个模型实例，其中 Gemini 9 个。前端使用已有动态目录，不需要硬编码新增选项。
