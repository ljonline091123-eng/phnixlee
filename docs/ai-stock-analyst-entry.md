# 独立 AI 证券分析师

入口：投研工作台 → AI证券分析师，`http://127.0.0.1:5173/#/research/analyst`。

用户搜索股票（中文、代码、拼音或首字母），选择资料周期和模型，查看本地资料覆盖后开始分析。结论页展示整体投资逻辑、短中长期趋势情景、成立与失效条件、驱动、风险和观察项。依据与数据页展示本次实际输入快照及原文链接；执行记录页显示真实阶段、计时、模型调用和 Skill 版本。失败可更换模型重新分析，旧记录保留。选择历史或刷新后恢复股票和周期；完成时从执行记录切换到结论页。

## 实现范围

- 复用已有 Model Hub、模型实例与中文股票搜索。新增业务 Skill `SENIOR_STOCK_TREND_ANALYST`，真实模型调用经过现有网关审计。
- 新建 `ai_stock_analysis`，保留模型、Skill版本、证据快照、覆盖、结果、错误和阶段历史。
- 初始分析只读本地量价、财务、F10、新闻、公告、研报/预测、问答、公司事实/分类和知识文档。新增每日跟踪会通过现有数据接口补采行情、日线、新闻与公告。
- 分类别预算控制输入，新闻与公告兼顾近期、重大事项及区间取样。摘要不等于全部原文；快照就是本次送给模型的资料。
- 公告只有标题时标记 `TITLE_ONLY`；不可读PDF正文不进入分析。公司候选事实保留候选状态。不同复权行情不混算。
- 输出包括整体判断及未来1至4周、1至3个月、6至12个月情景；证据支持度不等于涨跌概率。白名单外引用移除，缺引用降低支持度。
- 不把持股市值下降直接解释为净资金流出；动机与因果作为假设处理，金额换算须复核。相同标题但不同日期的回购等披露按独立事件保留。
- 使用独立前端及结果，不读取旧八维分数、不创建 `SelectionRun`、不将输出写成 `FoundationFact`。旧入口与数据保留。

## API

| 方法 | 路径（前缀 `/api/v1/ai-stock-analyst`） | 用途 |
|---|---|---|
| POST | `/context-preview` | 本地资料覆盖预览 |
| POST | `/analyses` | 创建证据快照并返回202，后台调用模型 |
| GET | `/analyses?market=HK&symbol=02533&limit=50` | 独立历史 |
| GET | `/analyses/{id}` | 状态、阶段、结果、模型与版本 |
| GET | `/analyses/{id}/evidence?offset=0&limit=20` | 本次证据分页 |
| POST | `/analyses/{id}/cancel` | 取消发布结果 |

创建和预览输入：`market`、`symbol`、`period_months`（1至60，默认12）；创建可指定 `model_instance_code`。前端仅列启用的真实模型。模型失败不生成程序替代结论。

## 增量迁移与回滚

当前项目启动会通过 ORM 创建新表并注册内置 Skill。也可执行 `cd backend; python scripts/migrate_stock_analyst.py`，脚本仅检查/创建本模块表和缺失的 Skill，多次执行不重复建表或覆盖已有 Skill。不改变旧表列结构，不清空任何业务数据。

推荐逻辑回滚：停用新 Skill，撤下新入口和路由，保留新表历史。恢复旧业务不需要删除表、恢复整库或重建旧图谱。本次备份只用于故障恢复，不能直接覆盖后续产生的数据。

初始分析与报告对话使用服务后台任务。刷新浏览器不影响执行；服务重启后将这些未完成记录明确标为失败并保留快照，由用户重试。每日跟踪使用已有数据库持久队列及带租约的 worker，区别于前述后台任务。取消分析可以阻止结果发布，不能保证撤销已发送的模型请求或费用。

## 2026-11-09 分析对话、用户确认与每日监控

### 使用方法

1. 打开已完成的分析。桌面左侧为独立阅读区，切换“分析结论 / 股票资料 / 依据与数据 / 执行记录”；右侧“AI研究伙伴”用于对话和每日跟踪，两区分别滚动。窄屏通过“报告与资料 / AI讨论与跟踪”切换，保留阅读位置与输入草稿。对话结合原报告、已确认观点、最近对话、最近每日复核和最新本地股票资料；可更换上方模型再发送。
2. 点击答复中的“编辑并确认更新报告”，修改最终判断和关注点后确认。报告上方显示确认版，原始报告保留；确认历史可展开查看。用户意见作为观点保存，不能直接升级为已验证事实。
3. 点击“关注价位 / 条件”。首次未设置监控时，AI根据报告、近期行情和公司事件生成并预填价格下限、上限、放量或缩量、均量窗口、新闻/公告关键词和长期关注点，同时显示理由、时间、模型及资料依据。已有监控先展示已保存条件，点击“重新生成AI建议”后可选择“应用AI建议”；手工编辑不会被晚到的新建议覆盖。价格为原币、不复权日线收盘价；量能为当日成交量除以前N个交易日均量，不包括当天。关键词支持每组任一命中，不表示经济影响已获验证。
4. 勾选每日监控并保存。默认北京时间18:00执行，时间可调整；可暂停或恢复。点击“立即检查”可立刻验收，不必等到次日。
5. “事件跟踪时间轴”按日期和尝试次数保存来源采集、条件触发、支持或挑战原判断、修正后的结论和下一步关注项；可查看实际证据并翻页。新判断在报告上方单独展示，旧结论不覆盖。
6. 点击报告中的“讨论这条结论”，或在“依据与数据”中点击“请AI解读这条资料”，将引用送至右侧，继续输入问题即可讨论。保留已有草稿，不强制切换左侧阅读内容。股票资料复用原个股详情的六类数据；对话记录单独保存实际输入快照，区分原报告证据与提问时的新资料。

自动链路：到期检查 → 持久队列 → 使用已启用且市场匹配的真实数据源补采并存储 → 条件硬规则比对 → LLM结合原报告、用户确认版本及最近7次成功/部分完成记录复核 → 保存证据、模型/Skill版本及时间轴。

每日自动执行同一关注任务去重一次。手动重试同日创建新尝试，保留失败及旧判断；正在执行时复用任务。服务离线期间不伪造过去日期的日报，恢复运行后检查当日任务。后端及治理执行器需要保持运行；外部 worker 部署还需运行项目 scheduler。

### 质量边界与回滚

- 行情缺失或超过4个自然日、数据来源失败、条件无法判断时标记“部分完成”，展示具体原因；模型失败不生成替代结论。4日时效阈值尚未接入交易所节假日历，长假期间可能出现保守的时效提示。
- 模型引用必须来自实际输入白名单；无依据不发布“支持/挑战”结论。持股比例或持股市值变化不能直接解释为资金净流出；亏损不能直接等同资金链紧张。引用校验不等同逐句财务解读正确，仍应核对原文。
- 新闻/公告采集沿用现有接口能力与供应商覆盖；首次关注补采近14日公告，新闻沿用接口返回窗口。每日证据有输入预算，不承诺全部长文逐字进入模型，也不承诺推理或预测准确率。
- 每日监控是收盘后的条件检查，不是盘中实时预警或自动交易。支持度是当前证据下的模型判断，并非收益概率。
- AI建议使用最近不复权行情与实际完整的此前交易日均量，过期或无行情时不给价位，量能样本不足时不采用量能阈值；建议不是目标价或买卖指令。生成和应用只修改草稿，监控时间、模型与启用状态由用户保存。模型格式不完整时有限重试，仍失败则保留错误与原文，不发布替代建议。
- 回滚优先暂停本模块关注任务、停用新增Skill并撤下新入口，保留五表、对话快照列和全部历史；原独立分析及旧八维工作台不受影响。Skill历史可按现有注册中心机制回滚。不要删列、删表或以整库覆盖实现功能回滚。

## 2026-11-10 对话图片与本地新闻公告引用

### 使用入口

在“投研工作台 → AI证券分析师 → AI研究伙伴”输入区直接按Ctrl+V粘贴截图，或点击“添加图片”。缩略图支持预览、移除；一次最多4张，单张压缩后不超过4MB，合计不超过12MB，支持PNG/JPEG/WebP。前端将最长边缩小到2400像素，后端再次校验真实格式、文件大小和像素数。

点击“引用新闻 / 公告”，可按类型和标题搜索当前股票全部已入库新闻公告，按日期倒序分页、跨页多选，一次最多8条。股票资料页的新闻、公告列表也可直接点击“引用到对话”；不再要求所选公告必须已经进入最初报告的证据快照。输入区显示所选标题，可逐条取消。发送失败保留当前草稿；已入队后执行失败的图片和引用仍保存在历史对话，重新编辑可恢复引用，图片需要重新添加。

### 模型与引用契约

- 图片通过真实图像输入发送，OpenAI兼容接口使用image_url，Gemini使用inlineData，Claude使用base64 image source；重试沿用同一附件。文本模型不能静默忽略图片，输入区会提示切换至支持图片的模型。型号识别可由模型config_json中的supports_images或supports_vision布尔配置覆盖。
- 当前股票身份由后端以market、symbol校验，不能引用其他股票或同代码其他市场的新闻公告，也不信任前端提交的文档正文。发送时冻结正文摘录、原文URL、来源、时间、正文长度与哈希；对话优先保留所选证据，预算不足时明确拒绝，不静默丢弃引用。
- 每条文档当前最多输入3000字正文摘录，长文标记truncated；仅有公告标题、尚未保存PDF正文时标记TITLE_ONLY，界面显示“仅标题，正文待补全”，不向模型声称已读正文。此入口引用已有本地数据，不另行下载PDF。
- 图片保存SHA256、尺寸和user-image证据ID，明确标识为“用户材料，未经独立核验”，不升级为官方事实。模型输出仍需通过证据ID白名单校验。原始图像不计入60000文字字符预算，多模态文字不能绕过预算。
