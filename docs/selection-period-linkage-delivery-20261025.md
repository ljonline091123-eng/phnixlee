## 2. 本轮交付

### 缺失数据补齐

- 批次和单股均可补齐全部缺口。
- 七个分析板块中的缺失板块可单独点击补齐：新闻、公告、财务、量价、资金、公司、图谱。
- 公司缺口接入既有 `company_graph_governance` 受控工作流，覆盖公司资料、股东、经营、司法、供应链和市值来源；抽取关系保持候选状态，不自动标记为已验证。
- 补齐后创建新的分析批次，旧批次及证据快照不覆盖；页面自动进入新批次。
- 图谱覆盖不完整时保持 `PENDING`，不再错误标记为 `GOVERNED`。

### 周期分析

- 分析周期单位为自然月，默认 3 个月，可配置 1 至 60 的自然数。
- A 股、新三板按上海时区，港股按香港时区计算自然日，避免 UTC 跨日造成一天偏差。
- 新闻、公告和日线量价按周期边界过滤；稳定身份和有效公司关系作为截止日上下文，不冒充周期内新事件。
- MVP 单股一次最多加载 80 篇周期新闻/公告。模型必须返回完整 `analyzed_document_ids`；漏读或越界引用会触发单股契约重试，不能发布为成功结论。
- 超过上下文上限的资料明确标记为 `PARTIAL`/数据限制，不伪造“全部分析完成”。

### 新闻公告联动 Skill

- 新增并接入 `STOCK_EVENT_LINKAGE_ANALYST`，与 `STOCK_SELECTION_ANALYST` 按顺序共同执行。
- 模型调用日志及候选证据保存两个 Skill 的代码和版本。
- 输出事件时间线、前后联动、历史主张兑现验证、冲突、高管/解禁线索、股东信心线索和关联证券影响。
- 时间接近只形成线索；原文未说明时，不推断高管辞职是为了减持等主观动机。

### 关联证券边界

- 只允许 `ACCEPTED` 的公司关系扩展关联证券，不按同板块、相似名称或模型猜测扩展。
- `RELATED_SECURITY_IMPACT` 必须同时引用当前证券原文、关联证券原文和已审核公司事实或实际图谱关系。
- 普通新闻、公告维度不得把关联证券文档当作当前股票事实。
- 前后联动校验来源文档和目标文档的实际发布日期顺序。

### 置信度

- 公告按正式披露来源处理；新闻按来源名称或域名分级。
- 同源转载只计算一个独立来源，不通过转载数量抬高置信度。
- 系统重新计算来源可靠性、时间一致性、跨文档支持、结构化事实支持、模型抽取置信度和冲突惩罚。
- 最终置信度是证据质量分，不是上涨概率或收益概率。

### 交互

- 显示自然月起止日期、周期文档数量、实际载入数量、事件联动数量和兑现验证数量。
- 缺失板块卡片直接提供“补齐该板块数据”操作。
- 显示补齐进度；完成后提示并自动打开新分析批次。
- 关联证券资料以独立区域展示，并明确其只是已审核关系驱动的影响线索。
- 原文引用可点击查看证据快照；分析页展示实际 Skill 链、知识库和图谱版本。

- 本轮没有新增数据库表和破坏性迁移，数据结构变更集中在 JSON 契约字段。
- 回滚代码：从远程备份分支创建恢复分支，不需要重置当前工作区。

## 5. 已知边界

- 单股周期内超过 80 篇可读披露时，当前版本会明确提示上下文预算不足，不会声称全量完成。后续可增加分批语义归纳再汇总的 Map-Reduce Skill。
- 港股司法、经营和供应链公开来源覆盖仍受数据源支持范围限制；无公开或无授权数据时保持 `MISSING`/`UNSUPPORTED`。
- LLM 联动结论仍是研究候选，需保留人工复核；系统不会据此自动交易。
