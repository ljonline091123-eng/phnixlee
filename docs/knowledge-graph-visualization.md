# 知识图谱可视化使用说明

本模块读取现有证券、公司、关系事实和动态信息，形成可交互的有限子图。旧公司关系页、股票详情、知识库治理、证据列表继续保留。

## 入口

- 数据中台 → 知识图谱：搜索全库股票或公司，并按市场筛选、分页。
- 股票详情 → 知识图谱：直接以当前股票为中心。
- 公司关系详情 → 知识图谱：直接以当前公司为中心。
- 模型实验室 → 知识库 → 知识图谱清单 → 可视化浏览：从该旧图谱内股票进入增强子图，使用下拉框切换图谱内证券。

旧图谱入口会补充当前已入库的公司主数据和动态资料，其查询范围在界面中明确说明。原图谱及其证据不被覆盖。双击公司或其他证券将进入该对象的完整关联范围，左上角返回按钮可回到上一中心。

## 阅读图谱

默认进入“总览”，画布只显示当前股票、发行公司及必要的身份关系；公司中心最多展示两条发行证券关系。下方提供九个领域入口：行业与板块及类型、股权与控制、财务与估值、量价与交易、新闻与公告、供应链与经营、司法事项、关联主体、来源与证据。这些入口是浏览分类，不会新增经济关系。

点击领域后，后端先筛选该类对象，再限制返回规模，保留从股票或公司通往对象的真实关系路径。页面每页展示最多 8 个领域对象，连同中心和中间路径最多显示 16 个对象；可按具体对象类型筛选、翻页或切换领域。图下列表保留完整名称，点击可查看属性与证据。面包屑可返回领域或总览。

证券使用蓝色，公司使用绿色，行业、主题与类型标签使用紫色。关系名称默认收起，选中节点或关系时突出相关路径，其余关系淡化。候选关系使用虚线，不代表已经验证的经济往来或因果关系。“原始关系”入口保留较完整的子图、图层和高级查询设置。

点击对象或关系，右侧显示对应属性、时间、来源和证据。持股关系显示持股比例及可用的比例口径；指标观测显示数值、单位和报告期；已有专属释义的分类标签可悬停查看释义，也可点击查看判定标准。没有专属释义的来源标签会显示缺口，不能用统一泛化说明替代真实定义。

证据可展开系统中保存的原始资料，带有效来源地址的资料也可打开原网页。原始数据中的来源字段保持原样，不能将未提供的币种、单位、主体或时间自行补成确定事实。

## 操作

- 拖动节点调整位置；拖动画布平移；滚轮缩放；左上角工具可放大、缩小、恢复 1:1 和适配画布。
- 双击证券或公司节点切换中心；键盘选中节点后，回车或空格打开详情，再用“以此对象为中心”继续下钻。切换中心时返回总览，上一个中心可用返回箭头恢复。
- 领域内可筛选类型、翻页、查看完整名称，选择“读取更多资料”扩大本次样本。待核实线索可单独启用。
- 在“原始关系”中，通过图层复选框和类型图例筛选画布；关联深度支持 1–3 层，对象上限支持 60、120、200，每类动态资料支持 3、5、10 条。
- 导出数据得到本次已加载子图及当前显示筛选信息；导出画布得到当前视角的 SVG。

卡片与领域页分别显示覆盖数量和已载入对象数。动态覆盖数量指对应证券的来源记录数；行业、板块、股权等计数来自当前有限邻域，不能视作全库总量。一份财报可形成多个指标对象，因此两种数量不一定相等。

出现截断提示时，界面展示的是部分资料。领域分页只翻阅已载入对象，并非遍历全部历史资料；提高对象数量、每类资料数量，或切换到具体证券继续探索。公司关联的其他证券不会自动共用某只股票的行情。缺少资料的领域仍可打开查看缺口。

右侧覆盖信息按查询范围评估。没有采集的数据保持缺口；没有查到司法记录不表示公司不存在诉讼，来源新闻提及也不自动升级为已核实事实。

## 实现与验证

前端为原生 SVG 交互模块，不新增第三方图形库。统一接口为 `/api/v1/knowledge-network/explore`，可选 `category` 为 `identity`、`classification`、`ownership`、`financial`、`market`、`disclosure`、`business`、`legal`、`evidence`。响应包含领域成员 `category_node_ids` 和计数口径 `coverage_scope`。原始证据读取接口为 `/api/v1/knowledge-network/evidence`。新旧证券、公司使用统一身份标识，原业务表的主键不变。

前端构建：在 `frontend` 目录执行 `npm run build`。

浏览器验证：在 `backend` 目录执行 `python validation/knowledge_network_ui_check.py`。脚本使用实际接口数据，覆盖全库分页、股票与公司身份连接、49.56% 持股比例、原文读取、拖拽缩放、证据及候选筛选、导出、公司全库搜索、类型筛选、港股、切换对象、错误重试、三类对象入口、旧图谱入口和手机布局。只有错误恢复步骤注入临时 503 响应。

分层导航验证：本地执行 `python validation/knowledge_navigation_ui_check.py`，使用运行系统真实数据验证九个领域、分类查询、分页、类型筛选、关系详情、原文、总览返回、港股、缩放、导出和手机布局。检查报告与截图保存在本地 `backend/validation/`，不作为业务数据入库。

集成期间可设置 `KG_VALIDATION_API_PORT`，把浏览器中的图谱读取转发到另一个真实后端端口，其他接口保持连接原运行系统；这不构造示例图谱数据。正式验收应使用默认 8000 端口。
