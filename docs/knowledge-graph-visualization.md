# 知识图谱可视化使用说明

本模块读取现有证券、公司、关系事实和动态信息，形成可交互的有限子图。旧公司关系页、股票详情、知识库治理、证据列表继续保留。

## 入口

- 数据中台 → 知识图谱：搜索全库股票或公司，并按市场筛选、分页。
- 股票详情 → 知识图谱：直接以当前股票为中心。
- 公司关系详情 → 知识图谱：直接以当前公司为中心。
- 模型实验室 → 知识库 → 知识图谱清单 → 可视化浏览：从该旧图谱内股票进入增强子图，使用下拉框切换图谱内证券。

旧图谱入口会补充当前已入库的公司主数据和动态资料，其查询范围在界面中明确说明。原图谱及其证据不被覆盖。双击公司或其他证券将进入该对象的完整关联范围，左上角返回按钮可回到上一中心。

## 阅读图谱

默认显示主数据与动态事实，来源证据图层可单独打开。证券使用蓝色，公司使用绿色，行业、主题与类型标签使用紫色。候选关系使用虚线，不代表已经验证的经济往来或因果关系。

点击对象或关系，右侧显示对应属性、时间、来源和证据。持股关系显示持股比例及可用的比例口径；指标观测显示数值、单位和报告期；已有专属释义的分类标签可悬停查看释义，也可点击查看判定标准。没有专属释义的来源标签会显示缺口，不能用统一泛化说明替代真实定义。

证据可展开系统中保存的原始资料，带有效来源地址的资料也可打开原网页。原始数据中的来源字段保持原样，不能将未提供的币种、单位、主体或时间自行补成确定事实。

## 操作

- 拖动节点调整位置；拖动画布平移；滚轮缩放；左上角工具可放大、缩小和适配画布。
- 双击证券或公司节点切换中心；键盘选中节点后，回车打开详情，空格切换中心。
- 通过图层复选框和底部类型图例筛选画布；图例可反复点击恢复显示。
- 关联深度支持 1–3 层；对象上限支持 60、120、200；每类动态资料支持 3、5、10 条。
- 导出数据得到本次已加载子图及当前显示筛选信息；导出画布得到当前视角的 SVG。

出现截断提示时，界面展示的是部分资料。提高对象数量、每类资料数量，或切换到具体证券继续探索。公司关联的其他证券不会自动共用某只股票的行情。

右侧覆盖信息按查询范围评估。没有采集的数据保持缺口；没有查到司法记录不表示公司不存在诉讼，来源新闻提及也不自动升级为已核实事实。

## 实现与验证

前端为原生 SVG 交互模块，不新增第三方图形库。统一接口为 `/api/v1/knowledge-network/explore`，原始证据读取接口为 `/api/v1/knowledge-network/evidence`。新旧证券、公司使用统一身份标识，原业务表的主键不变。

前端构建：在 `frontend` 目录执行 `npm run build`。

浏览器验证：在 `backend` 目录执行 `python validation/knowledge_network_ui_check.py`。脚本使用实际接口数据，覆盖全库分页、股票与公司身份连接、49.56% 持股比例、原文读取、拖拽缩放、证据及候选筛选、导出、公司全库搜索、类型筛选、港股、切换对象、错误重试、三类对象入口、旧图谱入口和手机布局。只有错误恢复步骤注入临时 503 响应。

集成期间可设置 `KG_VALIDATION_API_PORT`，把浏览器中的图谱读取转发到另一个真实后端端口，其他接口保持连接原运行系统；这不构造示例图谱数据。正式验收应使用默认 8000 端口。
