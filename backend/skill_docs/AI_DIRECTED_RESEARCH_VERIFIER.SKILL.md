# AI_DIRECTED_RESEARCH_VERIFIER

## 用途

对用户确认的单股研究方向执行一轮受控补证后的证据复核。该 Skill 只读取证据包，不直接写入事实、关系或图谱。

## 输入

- 股票身份、研究轮次和用户确认的 `direction_id`
- 补证前后证据快照
- 新闻、公告、财务、公司、研究和图谱等受控证据
- 证据引用白名单

## 输出

- 每个方向的 `SUPPORTED`、`CONTRADICTED`、`MIXED` 或 `INSUFFICIENT`
- 当前结论、置信度、支持证据、反证、剩余缺口和下一步来源
- 总体阶段摘要与风险提醒
- 复核失败时必须保留规划阶段的 `inference_candidates`；失败只影响二次复核状态，不得覆盖初步推理。

## 约束

- 文档证据必须带可在原文中连续核对的引句。
- 事实、推断、假设和未知分开保存；模型输出不能直接升级为事实。
- 模型返回规划结构或无法解析时，兼容保留文本但统一降级为 `INSUFFICIENT`。
- 模型失败、数据源失败和证据不足分开记录，不把失败当作查无证据。
- 重试模型复核时复用已完成的补证快照，避免重复采集。
