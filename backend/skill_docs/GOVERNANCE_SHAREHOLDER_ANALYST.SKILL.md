# GOVERNANCE_SHAREHOLDER_ANALYST

类型：`HYBRID`。任务路由：`selection_scoring`。副作用：`READ_ONLY`。

## 目标

综合控制权、股东增减持、回购、解禁、质押和高管变化，评价治理与股东稳定性。

## 输入边界

- 结构化股东事实必须带主体、动作、数量或比例、发生时间、来源和事实 ID。
- 语义方向只能来自已通过原文引用校验的公司治理分析。
- 时间接近只能形成关联线索；原文未说明时不得断言行为动机或因果。

## 执行与门禁

1. 盘点股东事实覆盖和治理语义证据。
2. 有事实但方向证据不足时只形成中性观测，不自动解释为利好。
3. 覆盖率和置信度按事实数量及语义证据共同计算。
4. 未达到方案门槛时返回 `INSUFFICIENT`，保留缺失说明。

## 输出契约

返回状态、方向、分数、覆盖率、证据置信度、股东事实数量、事实 ID、摘要和警告。

## 失败策略

幂等、只读、失败关闭。主体消歧失败、比例口径冲突或引用未通过校验时不生成方向分。
