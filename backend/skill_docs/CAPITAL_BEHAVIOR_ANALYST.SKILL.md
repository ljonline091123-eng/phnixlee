# CAPITAL_BEHAVIOR_ANALYST

类型：`DETERMINISTIC_HYBRID`。任务路由：`selection_scoring`。副作用：`READ_ONLY`。

## 目标

综合口径明确的资金流字段与同源量价行为，评估持续承接或交易活跃特征，但不确认主力或游资身份。

## 输入边界

- 资金数据必须具有明确字段名、日期、单位、来源和事实 ID。
- 只识别净流入、主力净流入等白名单字段，禁止任取首个数值作为资金净额。
- 成交量变化仅作为交易行为线索，必须与同源价格窗口配对。

## 执行与门禁

1. 统计已识别资金净额的正向比例。
2. 结合近期成交量比和同期价格方向进行有限调整。
3. 只有量价、没有明确资金字段时降低覆盖率和置信度并给出警告。
4. 未达到方案门槛时返回 `INSUFFICIENT`，不得写成“主力建仓”。

## 输出契约

返回状态、方向、分数、覆盖率、证据置信度、识别字段数量、正流入比例、量比、事实 ID 和警告。

## 失败策略

幂等、只读、失败关闭。单位冲突或不透明字段不参与计算，也不通过 LLM 猜测字段含义。
