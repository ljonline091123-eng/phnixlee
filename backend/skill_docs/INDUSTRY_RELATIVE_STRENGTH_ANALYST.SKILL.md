# INDUSTRY_RELATIVE_STRENGTH_ANALYST

类型：`DETERMINISTIC`。任务路由：`selection_scoring`。副作用：`READ_ONLY`。

## 目标

以标准行业成员为比较范围，衡量个股相对行业收益、同行中位收益和上涨广度。

## 输入边界

- 优先使用带分类体系、版本和审核状态的标准行业关系。
- 股票主数据行业字段仅作为兼容回退，主题或概念标签不能替代标准行业。
- 仅比较同市场、同周期、同口径的本地日线数据，评分时点之后的数据不可读取。

## 执行与门禁

1. 解析行业身份，取得不超过治理上限的同行集合。
2. 计算个股与同行的区间收益、同行中位数、超额收益和上涨广度。
3. 同行定价样本不足或个股行情不足时返回 `INSUFFICIENT`。
4. 当前没有行业基准指数时只能使用同行中位数，并在结果中明确口径。

## 输出契约

返回行业、分类体系、成员数、有效同行数、个股与同行收益、上涨广度、分数、覆盖率、分类证据 ID 和警告。

## 失败策略

幂等、只读、失败关闭。不因主题相似、名称相近或模型猜测扩充同行样本。
