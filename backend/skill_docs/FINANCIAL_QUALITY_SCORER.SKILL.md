# FINANCIAL_QUALITY_SCORER

类型：`DETERMINISTIC_HYBRID`。任务路由：`selection_scoring`。副作用：`READ_ONLY`。

## 目标

基于已治理财务事实评估收入、利润和资本回报质量。规则负责数值计算，已通过证据校验的财务语义结论只作为有限修正项。

## 输入边界

- 必须包含证券身份、评分时点、评价方案和结构化财务事实。
- 事实须保留指标编码、报告期、单位、修订状态和事实 ID。
- 只识别明确的营业收入同比、归母净利润同比、ROE 等字段，不猜测字段含义。

## 执行与门禁

1. 校验证券、报告期和数值类型，拒绝跨证券或未来期数据。
2. 计算可复现的指标调整值，并限制单一指标影响范围。
3. 缺失指标不填零、不填中性值，也不由模型补造。
4. 覆盖率或证据置信度未达到方案门槛时返回 `INSUFFICIENT`，原始观测分仅供诊断。

## 输出契约

返回维度编码、`SUPPORTED/INSUFFICIENT`、方向、0-100 分或空值、覆盖率、证据置信度、指标明细、事实 ID、摘要和警告。

## 失败策略

同一候选、评分时点和方案版本下幂等执行。字段冲突、单位不明或计算异常时失败关闭并保留审计，不生成替代分数。
