# 新闻公告结构化事件治理

输入为已登记的证券身份、治理批次和有界文档数。只允许通过 govern_stock_documents 和 Foundation 服务写入白名单表。

1. 使用证券—公司映射定位主体，不按股票简称猜公司身份。
2. 新闻使用保存的正文；检索摘要必须从登记的原文主机有界补取正文，不把检索摘要当成全文。公告正文缺失时只从允许的官方 PDF 主机有界下载。下载额度耗尽标记待续作，失败、扫描件、正文截断均保留缺口。
3. 原文保存在版本化 FoundationEvidence，保留来源记录、URL、披露时间和内容哈希。
4. 先调用真实模型阅读全文，形成概览、章节主题、因果和时间线及不确定性，再调用模型转为结构化事件、参与主体、数字指标、分维度影响和关键关系。只处理与本任务公司明确有关的事件，不把其他公司或板块整体事件归入该公司。完整覆盖正文的实质主题与末尾结论，不能只提取标题或首段。每次最多40000字，超限或来源提取截断明确保留PARTIAL。
5. 精确验证引文确实存在于送入模型的正文。仅允许忽略 PDF 排版空格与换行来定位原文，并保存原文中的连续引文；数字、文字和标点必须相符，禁止模糊匹配。无法验证的输出不得写入事实。
6. NEWS_EVENT、NOTICE_EVENT 写入已有 FoundationFact，只能为待审核候选；保存模型调用、模型版本、Skill 版本、执行批次和证据 ID。
7. 相同原文哈希与 Skill 版本幂等；原文/Skill 版本变化创建新版本，保留历史事实。发现旧候选把检索摘要标为全文时，通过受控事实审核服务追加驳回记录，保留原事实、证据及报告，不覆盖或删除历史。
8. 每批明确总量、已分析量、正文缺失量、待处理量和失败原因。续作配额兼顾失败重试和新文档推进，重复失败不能阻塞全部文档。继续治理只补未完成文档，不能把有界样本的成功声明为全量完成。

9. 披露转述事实、作者/专家观点、模型推断分开保存并注明归属。套利动机、违规判断只能保留为对应主体的观点，未经原始裁决核验不能视为官方结论。法院程序性驳回不能转成实体违法认定。
10. 影响分利润、现金流、融资、治理、监管、经营、股价。原文明示利润减少则利润负向；现金流影响标注支付条件。无股价依据不推出确定涨跌，禁止一律UNKNOWN，也禁止一律利空。
11. 数值保留原文、单位、期间、估计或上下限语义，程序精确校验数字与单位后标准化为元/股/百分比。参与方只解析到已存在的唯一身份，否则为文档提及，禁止按别名臆造工商身份。关系候选与事件候选分别落入既有FoundationFact，端点、引文、归属、版本可查。
12. 专项入口支持选择指定新闻公告，独立创建已有Agent治理任务，查看全文语义成果与历史版本。相同正文、Skill及语义契约版本幂等；新版本重分析保留旧结果。
13. 支持人工逐字段核验事件、指标、影响、主体与关系。审核动作必须记录审核人、意见、对象、字段、前值、新值、时间、事实ID和版本键；禁止覆盖或删除旧版本。
14. 人工修改通过受控审核服务生成新的候选版本和新的候选事实，原候选追加驳回记录并保留血缘。人工“确认结构”只表示抽取结构已人工核对，不得把FoundationFact从PENDING/CANDIDATE自动升级为已验证事实。
15. 人工反馈可触发定向重分析；模型必须同时读取当前结构化版本与反馈，优先保持未被质疑且有原文证据的字段。相同正文最多两轮人工反馈重分析，超过上限必须阻断并转人工处理，不能无限循环消耗模型调用。
16. 审核与重分析仍执行原文引文、数字单位、主体名称和事实性质门禁。人工意见不能替代公告、监管文件、法院文书等外部交叉验证，也不能让作者观点、媒体转述或模型推断冒充权威结论。
