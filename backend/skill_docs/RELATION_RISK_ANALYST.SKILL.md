# RELATION_RISK_ANALYST

类型：`HYBRID`。任务路由：`selection_scoring`。副作用：`READ_ONLY`。

## 目标

基于已核验的供应链、经营往来、司法事项和外部事件关系，评价产业链与外部韧性。

## 输入边界

- 关系必须具有业务谓词、主体、客体、证据、时间和审核状态。
- `HAS_RECORD`、`SUPPORTED_BY` 等资料归属边不属于业务事实。
- `CANDIDATE`、`PENDING`、关键词提及等候选关系只用于提示，不参与评分。

## 执行与门禁

1. 排除资料归属边，区分已核验关系与候选关系。
2. 仅 `VERIFIED`、`SOURCE` 或 `ACCEPTED` 业务关系参与覆盖和证据集合。
3. 对诉讼、质押、违约、处罚等已核验风险关系进行有限扣分。
4. 没有足够已核验关系时返回 `INSUFFICIENT`，不以候选关系补足覆盖。

## 输出契约

返回状态、方向、分数、覆盖率、证据置信度、已核验/候选关系数、风险关系数、关系 ID、摘要和警告。

## 失败策略

幂等、只读、失败关闭。主体身份不统一、审核状态缺失或证据不可追溯时不纳入评分。
