# PRICE_RISK_ANALYST

类型：`DETERMINISTIC`。任务路由：`selection_scoring`。副作用：`READ_ONLY`。

## 目标

按同源日线计算短周期收益、波动、最大回撤和成交量变化，形成可重复验证的价格风险评价。

## 输入边界

- 行情必须属于同一证券、周期、复权口径和评分时点。
- 需要交易日期、收盘价和可选成交量；无效或非正价格不得参与计算。
- 不读取评分时点之后的数据，不预测未来价格。

## 执行与门禁

1. 按交易日期排序并计算 5 日、窗口收益、收益波动和最大回撤。
2. 成交量比只比较同一序列中的近期与此前样本。
3. 样本覆盖未达到方案门槛时返回 `INSUFFICIENT`。
4. 分数表达当前趋势和回撤结构，不等于上涨概率或买卖建议。

## 输出契约

返回状态、方向、分数、覆盖率、证据置信度、窗口指标、行情事实 ID、摘要与样本不足警告。

## 失败策略

幂等、只读、失败关闭。日期乱序可确定性排序；口径冲突和无效价格不做模型修复。
