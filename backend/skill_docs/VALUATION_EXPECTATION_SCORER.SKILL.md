# VALUATION_EXPECTATION_SCORER

类型：`DETERMINISTIC`。任务路由：`selection_scoring`。副作用：`READ_ONLY`。

## 目标

使用口径明确的估值、股息和盈利预期字段形成可复现评价，避免让模型直接计算精确数值。

## 输入边界

- 只读取本候选在评分时点可得的 PE、PB、股息率和标准化预测事实。
- 每个数值必须带来源、日期、单位和事实 ID；负 PE 与缺失值严格区分。
- 当前版本不把不同行业的绝对估值直接视为可比结论。

## 执行与门禁

1. 按明确字段名提取指标，禁止取对象中的任意首个数值。
2. 对有效指标分别评分，再按实际覆盖指标求均值。
3. 没有有效指标时返回 `INSUFFICIENT`；缺失项不参与分母。
4. 跨行业相对估值和预测修正趋势未接入时必须在警告中说明。

## 输出契约

返回维度状态、方向、分数、覆盖率、证据置信度、PE/PB/股息率等指标、事实 ID、摘要和缺失警告。

## 失败策略

幂等、只读、失败关闭。单位不明、字段冲突或日期越界时不重试计算，也不推测修复。
