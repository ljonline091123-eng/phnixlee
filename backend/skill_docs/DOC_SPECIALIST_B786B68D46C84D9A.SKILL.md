# 通用证据事实治理

在专项能力暂缺时抽取最小、有原文支持的候选事实；没有目标对象直接事实时返回无相关事实。不得为了完成率制造事件、关系或影响方向。


## 专项语义规则
# 证券与板块市场统计类文档专项提取规则

## 目标
从证券与板块市场统计类文档中提取结构化事实数据，确保主体、数值、单位和证据定位的准确性。

## 提取规则
1. **主体边界**：仅提取原文中明确出现的行业名称、个股名称及代码，不得推断或生成。每个主体名称必须逐字匹配原文，包括全称、简称及括号内代码。
2. **数值与单位**：所有数值（如涨跌幅、换手率、资金流量）必须与原文完全一致，包括正负号、小数点及单位（万元或亿元）。禁止单位换算或四舍五入。
3. **资金流归属**：严格区分行业整体资金流与个股资金流。行业资金流（如“机械设备行业主力资金净流出10.68亿元”）与个股资金流（如“精智达主力资金净流出7369.27万元”）必须分别提取，不得混淆或合并。
4. **事实与观点**：仅提取表格中的事实性数据。免责声明、评论或预测性内容（如“不构成投资建议”）不得作为事实提取。
5. **证据定位**：每个提取项必须附带原文中的证据定位，包括表格名称、行号或列名，以便审计。
6. **不确定项处理**：若原文存在歧义、缺失或无法确认的数值，必须标记为“不确定”并请求用户确认，不得自行补全。
7. **输出格式**：以结构化方式输出，每个主体一行，包含主体名称、代码、字段名、数值、单位及证据定位。

## 输出示例
```
主体名称 | 代码 | 字段名 | 数值 | 单位 | 证据定位
机械设备 | - | 主力资金净流量 | -10.68 | 亿元 | 正文第X段
罗博特科 | 300757 | 主力资金净流量 | 43403.43 | 万元 | 机械设备行业资金流入榜第1行
沃尔德 | 688028 | 主力资金净流量 | -32190.82 | 万元 | 机械设备行业资金流出榜第1行
```

## 注意事项
- 行业资金流与个股资金流必须分别提取，并在输出中明确区分。
- 所有数值必须保留原始单位，不得转换。
- 证据定位必须具体到表格名称和行号，以便审计。
- 若原文存在不确定项，必须标记为“不确定”并请求用户确认。

## 契约输出要求
- 必须输出符合extraction_schema的JSON对象，不得输出Markdown表格。
- 每个事件必须包含event_date，格式为YYYY-MM-DD，若原文未提供完整年月日则设为null。
- 每个指标必须包含raw_value和unit，raw_value必须保留原始符号和单位，不得添加或删除负号。
- 不得输出normalized_value、normalized_unit等模型推断字段。
- 不得输出impacts和relations中的模型推断内容，除非原文明确陈述。
- 所有提取项必须附带evidence_quote，且evidence_quote必须逐字引用原文。
- 表格数据必须提供table_index、table_row、table_column和evidence_bundle，其中evidence_bundle必须包含表头和对应数据行。
- 若原文存在不确定项，必须在uncertainties中列出，但不得与已提取的事实矛盾。
